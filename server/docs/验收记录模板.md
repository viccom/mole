# moleAgent_Serv 验收记录模板

## 使用说明

本模板用于记录《改进方案.md》各改进项执行后的验收结果。

使用建议：

- 每完成一个改进项，就复制一份“单项验收记录模板”进行填写
- 每完成一个阶段，就补一份“阶段验收汇总”
- 全部阶段结束后，再补一份“整体验收结论”

勾选规则：

- `[x]` 已确认完成
- `[ ]` 未完成或未验证
- `[N/A]` 当前不适用，但必须说明原因

结论规则：

- `通过`
- `基本通过`
- `不通过`
- `暂不适用`
